# Editions

Deep Radio is available in two editions.

| | Deep Radio | Deep Radio Pro |
|---|---|---|
| **Memory (each station)** | 128 GB SSD, 8 GB RAM | 128 GB SSD, 16 GB RAM |
| **Transmitter frequency range** | 50 MHz – 6 GHz | 50 MHz – 6 GHz |
| **Receiver frequency range** | 50 MHz – 1700 MHz | 50 MHz – 6 GHz |
| **Receiver max. sampling rate** | 2.4 MS/s | 20 MS/s |

**Choose Deep Radio Pro** if you need to receive above 1.7 GHz (for example, Wi-Fi or higher cellular bands) or need wider receive bandwidth.

Full details: [Specifications](../hardware/specifications.md).
