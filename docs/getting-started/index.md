# Getting Started

## What Is Deep Radio?

Deep Radio is an SDR-based platform designed:

- to teach and learn the fundamentals of signal processing and wireless communications
- to process real-time signals
- to develop applications of deep learning in the wireless domain

## What's in the Box

Each Deep Radio setup has a **transmitter** and a **receiver** station. Each station includes:

- Radio unit
- Monitor
- Keyboard and mouse

See [Editions](editions.md) for the differences between **Deep Radio** and **Deep Radio Pro**, and [Specifications](../hardware/specifications.md) for full details.

## Who It's For

- **Laboratory courses:** Digital Signal Processing, Analog Communications, Digital Communications, Wireless Communications, and Machine Learning for Wireless Communications
- **Projects:** B.E./B.Tech final-year projects, M.E./M.Tech dissertations, M.S. research projects, and Ph.D. research and prototype development
